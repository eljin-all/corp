
# Лабораторная работа: Аспектно-ориентированное программирование в Java

## Описание проекта

Консольное Java-приложение, демонстрирующее:
- Иерархию наследования классов (`Person` → `Student`, `Teacher`, `Employee`)
- Работу с коллекцией объектов базового класса (`ArrayList<Person>`)
- Аспектно-ориентированное программирование (АОП) с использованием **AspectJ**
- Логирование вызовов методов, параметров, возвращаемых значений и исключений

---

## Требования

Для сборки и запуска проекта необходимо:

| Компонент | Версия |
|---|---|
| **JDK** | 17 или выше |
| **Apache Maven** | 3.9 или выше |
| **AspectJ** | 1.9.21 (подтягивается автоматически через Maven) |
| **ОС** | Windows / Linux / macOS |

## Сборка проекта

Откройте терминал (CMD / PowerShell / bash) и перейдите в папку с `pom.xml`:

Выполните сборку:

```bash
mvn clean package
```

После успешной сборки в папке `target/classes` появятся скомпилированные `.class` файлы.

---

## Запуск приложения


```bash
mvn exec:java
```

Запускайте двойным кликом.

---

## Использование приложения

После запуска появится меню:

```
---------------------------
Это программа для создания классов вида: студент, учитель, служащий
---------------------------
1. Добавить новый элемент
2. Удалить элемент по индексу
3. Вывод всех элементов в консоль
4. Сравнение двух элементов на равенство
5. Завершение работы приложения
Выберите действие:
```

### Пункт 1: Добавить новый элемент
- Выберите класс: `1` — Студент, `2` — Учитель, `3` — Служащий.
- Выберите тип: `1` — Пустой объект, `2` — Заполненный объект.
- При выборе «Заполненный» введите имя, рост (10–500 см) и дополнительные поля.

### Пункт 2: Удалить элемент по индексу
Введите номер объекта (начиная с 1).

### Пункт 3: Вывод всех элементов
Отображает список всех объектов с указанием класса и данных.

### Пункт 4: Сравнение двух элементов
Введите два индекса — программа покажет, равны ли объекты.

### Пункт 5: Завершение работы
Выход из приложения.

## АОП-логирование

Аспект `LoggingAspect` автоматически логирует:

- **Имя вызываемого метода**
- **Параметры метода**
- **Возвращаемое значение**
- **Неотловленные исключения**

Пример вывода:

```
[LOG] Вызов метода: main
[LOG] Параметры: [[]]
[LOG] Вызов метода: objectCreating
[LOG] Параметры: [[], 1, 1]
[LOG] Метод objectCreating вернул: null
[LOG] Вызов метода: listPrint
[LOG] Метод listPrint вернул: null
```
